# NSRW v0.6.0 — Research verification and MomentBound

This release adds `nsrw-verify`, an installed command for running
research checks with named inputs and explicit result scope. Each report
records input hashes and the method used. An optional execution manifest
links the report digest to the observed implementation files, dependencies
and Python runtime. GitHub Actions runs the public forced-shear and
normalized-factor checks and retains their reports and manifests.
Manifest mode refuses to publish a result if required implementation
files or the pinned interval dependency cannot be identified.

The workflow was exercised locally on rational matrix inverses, a second
interval implementation of the normalized factor, a manufactured
Navier–Stokes solution and the retained P1 Lean archive. The archive check
reviewed ten recorded declarations and rejected a repacked control that
omitted the mass-zero hypothesis. It reused the original Lean evidence.

MomentBound adds the previously reviewed conditional coefficient and
normalized angular-moment results. Their mathematical scope is governed by
the separate dated receipts. The MB-08 operator bounds passed development
compilation. Fixed source-profile construction, the cutoff jet and the
same-reset amplitude conditions remain open.
