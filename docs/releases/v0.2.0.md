# NavierStokes Research Workbench v0.2.0

This release establishes the first public, evidence-bound M4-P research gate.
It expands the workbench beyond paper extraction and static declaration checks
while keeping every mathematical claim narrower than the executable evidence.

## Highlights

- closes M3 engineering with an explicit noncomputable source-witness boundary;
- adds the M4-P Support, Cone, Moment, and falsification obligation pipeline;
- binds declared source quantifiers to normalized Lean declaration signatures
  and ordered source fragments;
- requires structured compiled evidence for three pinned Lean targets, including
  source commit, toolchain, exit status, `.olean` identity, and dependency
  surface hashes;
- evaluates six claim/evidence mutations against the clean baseline delta;
- makes source-file hashes portable across Windows CRLF and Linux LF checkouts;
- adds cross-platform Python, deterministic replay, research-custody, and scoped
  Lean build jobs to GitHub Actions;
- keeps SPAR as a secondary diagnostic that cannot override the NSRW hard gate.
