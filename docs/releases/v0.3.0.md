# v0.3.0 -- M5 scaling-atlas checkpoint

Release date: `2026-09-12`

Release status: `HELD[HOSTED_CI_PENDING]`

Version 0.3.0 expands the M5 code surface from one bounded `H_scaling`
vertical slice to a fixed `OutgoingDilation` scaling-atlas interface. It does
not claim a complete source-bound atlas, a Lean theorem proof, paper--Lean
semantic equivalence, a selected-source witness, or a solution of the
Navier--Stokes Millennium problem.

## Included checkpoint surface

- Adds selected-declaration batch normalization through one streaming raw
  export reader, without reading proof values or falling back to Lean source
  text.
- Defines ten reviewed-static scaling-law entries and exact `Fraction`
  exponent algebra. Degree-zero outputs are candidates for the next
  mathematical question, not invariants or estimates.
- Closes P1-A: candidate semantic digests cannot be supplied by the caller to
  production atlas admission. Admission requires a separately reviewed ledger
  file and a code-pinned physical SHA-256.
- Adds regression controls for source metadata drift, type-projection drift,
  raw-hash mismatch, law-metadata mutation, and recomputed attacker candidate
  digests.
