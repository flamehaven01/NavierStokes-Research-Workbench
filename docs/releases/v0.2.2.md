# v0.2.2 -- Evidence integrity and research-lab presentation

Release date: `2026-09-11`

Publication status: `NOT_RELEASED[SUPERSEDED_BY_V0.2.3_AUDIT_CLOSURE]`

This file is a historical implementation checkpoint, not a published release
note. Hosted run `34579077366` passed the v0.2.2 candidate, after which
post-implementation review found the bounded defects tracked in
[`V0.2.2_AUDIT_PATCH_TO_V0.2.3_CLOSURE.md`](../V0.2.2_AUDIT_PATCH_TO_V0.2.3_CLOSURE.md).

This release strengthens how NSRW records and validates bounded evidence. It
does not add a Navier--Stokes theorem, reproduce the selected source witness,
or establish paper--Lean semantic equivalence.

## Highlights

- Adds a v3 M4-P replay fixture with explicit historical-replay and same-run
  live-evidence modes.
- Adds language-neutral 14-case mutation oracle metadata with separate full-manifest
  and direct-evaluator expectations.
- Moves Lean target builds, observed `.olean` discovery, dependency
  normalization, receipt generation, live-manifest construction, and
  run-specific provenance into `nsrw.lean_receipt`.
- Normalizes relative Lean source and dependency roots before calculating
  source-relative artifact records.
- Rejects duplicate JSON keys, non-finite numbers, excessive nesting, and
  excessive parsed-node counts.
- Corrects the M3 execution record so an installed executable is not mistaken
  for an executed successful build.
- Adds an explicit metadata-only migration record instead of presenting
  reconstructed v3 fields as historical execution evidence.
- Repositions the public project as an open research-lab workbench and replaces
  unexplained internal terminology with plain descriptions of the checks.

## Research boundary

The compiled targets and bounded Python checks are evidence about their stated
inputs and execution scope. They do not prove the informal manuscript correct,
do not provide a numerical `TailData` witness, and do not solve the Millennium
Prize problem. M4-S therefore remains
`HELD[NONCOMPUTABLE_SOURCE_INSTANCE]`, while paper--Lean semantic equivalence
remains an open research obligation.
