Release date: 31 October 2026. Software 0.5.0, mathematical manuscript P01 0.5 and software manuscript P02 0.6 are separate version axes.

## Research

For each fixed pinned-source Profile and every sufficiently small positive parameter, a point inside the first repair window has mass history zero and strictly positive angular history at the same point. The quantitative extension supplies a positive local-angular lower bound independent of the selected mass-zero witness and a normalized cutoff-plateau bound.

The ten quantitative/normalization declarations retain proof checkpoint `fba27381bcfda3af6f03e2fbae82f6db016ca534`, execution checkpoint `7f29ebf0e2b894bf598144628230ae09df436c3d` and the 22 October receipt. This software release is not a new Lean execution or independent reproduction.

## Computation

A new Python standard-library Fraction prototype computes rigorous exponential and expm1 core-scalar enclosures on a declared absolute dyadic grid. It emits/recomputes deterministic records at 128, 256 and 512 fractional bits. The main denominator's lower endpoint is positive; positive ratios use lower(numerator)/upper(denominator). Tests reject a forged endpoint quantum, malformed/duplicate JSON and attempted scope promotion. See the [method](../P2_CORE_SCALAR_METHOD_2026-10-31.md) and [observed execution](../P2_CORE_SCALAR_OBSERVATION_2026-10-31.md).

These records do not compute affine-coefficient integrals, numerical q>0, a ResetWitness/K, an explicit source Profile, a root bracket or a numerical J certificate. The large second-bump scale is retained as a lower-bound expression, not a two-sided I01 enclosure.
